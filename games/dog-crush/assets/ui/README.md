# Animal Café — smoothed PNG assets

Replacement for the first asset ZIP. All 34 PNGs are included with the same relative filenames and native dimensions.

The 26 newly extracted UI sprites now use antialiased edge transparency. Hard-cut fringes were contracted by approximately one source pixel and the alpha edge was softened; interior color/detail was retained. Edges were inspected over light and dark backgrounds. The original supplied food icons and the previously antialiased Home title and Home PLAY asset are preserved. Both backgrounds are unchanged.

manifest.json lists dimensions, alpha information and treatment for every file. This is edge cleanup, not a resolution increase. Avoid enlarging small raster sprites substantially beyond their native dimensions.

Backgrounds: 1240 × 1920. Centered phone design area: 1080 × 1920 (80 extra pixels per side).

Blank panels, buttons and level tiles support separately rendered dynamic labels. Single-line titles match current layouts; stacked titles are alternatives. Home-icon and Retry are the failed-popup controls. The four screen mockups remain in the separate mockup ZIP.

These assets are raster recreations from the flattened mockups and original provided assets, not layered vector files. Some visual variation from the mockups remains. No game code or font files are included.
